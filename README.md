# Netflix-Data-Analysis
Exploratory Data Analysis of Netflix Movies and TV Shows using Python, Pandas, Matplotlib 
# Netflix Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Analysis Performed

* Data loading and cleaning
* Missing value analysis
* Movies vs TV Shows comparison
* Top 10 countries by content
* Content added over the years
* Movie duration analysis
* TV show seasons analysis
* Content ratings analysis
* Movies and TV shows by release year

## Project Files

* `Netflix_Data_Analysis.ipynb`: Jupyter Notebook containing the analysis and visualizations.
* `netflix_titles.csv`: Dataset 

## How to Run

1. Clone or download this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn jupyter`
3. Open Jupyter Notebook.
4. Run `Netflix_Data_Analysis.ipynb`.

## Conclusion

This project explores Netflix content distribution, genres, release years, countries and other patterns through data analysis and visualization.
